# Yanmet

Yanmet, kullanıcıların merak ettikleri konuları hızlı ve sade bir arama deneyimiyle keşfetmesini sağlayan modern bir web uygulamasıdır.

## Özellikler
- Türkçe arama odaklı arayüz
- Mobil uyumlu tasarım
- Hızlı erişim butonları
- Wikipedia API ile canlı arama sonuçları
- Bağlantı yoksa yerel yedek akışla çalışma

## Teknolojiler
- Vite
- JavaScript
- Vercel
- Wikipedia API

## Çalıştırma
```bash
npm install
npm run dev
