# Yanmet
Yanmet, kullanıcıların merak ettikleri konuları hızlı ve sade bir arama deneyimiyle keşfetmesini sağlayan modern bir web uygulamasıdır. Türkçe odaklı, mobil uyumlu ve hızlı erişimli bir arama deneyimi sunar. Wikipedia API üzerinden canlı sonuçlar verir; bağlantı yoksa güvenli bir yerel yedek akışla çalışır.
